Priority Queue Data Structure
1. Definition of Priority Queue
A Priority Queue is a data structure in which every element has an associated priority.

Unlike a normal queue, elements are removed according to their priority, rather than strictly following FIFO.

If two elements have different priorities:

The element with higher priority is processed first.

The element with lower priority is processed later.

Example:

Element	Priority
A	3
B	1
C	2
Assuming smaller priority number means higher priority, the processing order is:

B → C → A
A priority queue is commonly used in:

CPU Scheduling

Dijkstra's Algorithm

Prim's Algorithm

Network Routing

Hospital Emergency Systems

Task Scheduling

2. Priority Queue ADT
ADT (Abstract Data Type) defines the operations and behavior of the data structure without focusing on its implementation.

A Priority Queue supports the following operations:

Operation	Description
Enqueue()	Insert an element with a priority
Dequeue()	Remove the highest-priority element
Peek()	View the highest-priority element
is_Empty()	Check whether the priority queue is empty
is_Full()	Check whether the priority queue is full
display()	Display all elements with their priorities
3. Representation of Priority Queue
A priority queue can store both:

Element

Priority

For example:

Element:   A    B    C
Priority:  3    1    2
The element with priority 1 has the highest priority.

Therefore:

B → C → A
4. Priority Queue Code in Python
class PriorityQueue:

    def __init__(self, size):
        self.size = size
        self.queue = []

    # Check Empty
    def is_Empty(self):
        return len(self.queue) == 0

    # Check Full
    def is_Full(self):
        return len(self.queue) == self.size

    # Enqueue Operation
    def Enqueue(self, item, priority):

        if self.is_Full():
            print("Priority Queue Overflow!!")

        else:
            self.queue.append((item, priority))
            print(f"{item} entered with priority {priority}")

    # Dequeue Operation
    def Dequeue(self):

        if self.is_Empty():
            print("Priority Queue Underflow!!")

        else:
            highest_priority_index = 0

            for i in range(1, len(self.queue)):
                if self.queue[i][1] < self.queue[highest_priority_index][1]:
                    highest_priority_index = i

            item = self.queue.pop(highest_priority_index)

            print(f"{item[0]} Removed From Priority Queue")

    # Peek Operation
    def Peek(self):

        if self.is_Empty():
            print("Priority Queue is Empty!!")

        else:
            highest_priority_index = 0

            for i in range(1, len(self.queue)):
                if self.queue[i][1] < self.queue[highest_priority_index][1]:
                    highest_priority_index = i

            print(
                f"Highest Priority Element is {self.queue[highest_priority_index][0]}"
            )

    # Display Operation
    def display(self):

        if self.is_Empty():
            print("Priority Queue is Empty!!")

        else:
            print("Elements with Priorities:")

            for item, priority in self.queue:
                print(f"Element: {item}, Priority: {priority}")

Definition
Enqueue means inserting an element along with its priority into the Priority Queue.

Algorithm: ENQUEUE(item, priority)
Step 1: Check whether the Priority Queue is full.

Step 2: If the queue is full:

Print "Priority Queue Overflow"
Stop.

Step 3: Insert the item and its priority.

Step 4: Stop.

Example
Suppose:

Size = 5

Priority Queue = [ ]

[A, 3]

Although A was inserted first, B will be removed first because it has the highest priority.

Priority order:

B → C → A
8. Dequeue Operation
Definition
The Dequeue operation removes the element having the highest priority.

In this implementation:

Smaller Priority Number = Higher Priority
Example:

Element	Priority

B	1
C	2
The highest-priority element is:

B
because:

Priority = 1
Algorithm: DEQUEUE()
Step 1: Check whether the Priority Queue is empty.

Step 2: If empty:

Print "Priority Queue Underflow"
Stop.

Step 3: Assume the first element has the highest priority.

Step 4: Compare its priority with all other elements.

Step 5: Find the element with the smallest priority value.

Step 6: Remove that element.

Step 7: Display the removed element.

Step 8: Stop.

15. Overflow and Underflow
Priority Queue Overflow
Overflow occurs when we try to insert an element into a full Priority Queue.

Condition:

Number of elements = Maximum Size
Example:

Size = 3

[(A,3), (B,1), (C,2)]
Trying:

Enqueue(D, 1)
Output:

Priority Queue Overflow!!
Priority Queue Underflow
Underflow occurs when we try to remove an element from an empty Priority Queue.

Example:

Priority Queue = [ ]
Trying:

Dequeue()
Output:

Priority Queue Underflow!!

17. Applications of Priority Queue
Priority Queues are used where some tasks are more important than others.

1. CPU Scheduling
Processes with higher priority are executed first.

High Priority Process
        ↓
Executed First
2. Dijkstra's Algorithm
Priority Queue helps select the vertex with the smallest distance.

3. Prim's Algorithm
It helps select the edge with minimum weight.

4. Hospital Emergency System
Patients with more serious conditions are given higher priority.

5. Network Routing
Important packets can be processed before lower-priority packets.

18. Difference Between Normal Queue and Priority Queue
Normal Queue	Priority Queue
Follows FIFO	Follows Priority
First inserted element is removed first	Highest-priority element is removed first
All elements have equal importance	Each element has a priority
Used in normal scheduling	Used in priority scheduling
Enqueue at Rear	Insert with priority
Example:

Normal Queue
10 → 20 → 30
Removal order:

10 → 20 → 30
Priority Queue
10 Priority 3
20 Priority 1
30 Priority 2
Removal order:

20 → 30 → 10
19. Important Viva Questions
1. What is a Priority Queue?
A Priority Queue is a data structure in which elements are removed according to their priority.

No. Elements are generally processed according to priority.

The element with the smallest priority number.

It inserts an element along with its priority.

Peek displays the highest-priority element without removing it.

It occurs when insertion is attempted in a full Priority Queue.

It occurs when deletion is attempted in an empty Priority Queue.
