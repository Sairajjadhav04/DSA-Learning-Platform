1. Stack – Definition
A Stack is a linear data structure in which insertion and deletion of elements are performed only from one end called the TOP.

Stack follows the principle:

LIFO – Last In, First Out

This means the element inserted last is removed first.

Example
Suppose we perform:

Push(10)
Push(20)
Push(30)
The stack becomes:

TOP → 30
       20
       10
If we perform Pop(), 30 will be removed first.

TOP → 20
       10
2. Stack ADT
Definition of ADT
ADT (Abstract Data Type) is a logical description of a data structure that specifies:

What data is stored

What operations can be performed

What those operations do

It does not specify how the operations are implemented.

Stack ADT
A Stack ADT can be defined as:

Stack ADT
Data:
    Collection of elements
    TOP indicating the topmost element

Operations:
    Push()

    IsFull()
    Display()
Your program implements the Stack ADT using an array.

21. Important Difference: Stack vs Queue
Stack	Queue
Follows LIFO	Follows FIFO
Insertion at TOP	Insertion at REAR
Deletion from TOP	Deletion from FRONT
Last inserted element removed first	First inserted element removed first
Example: stack of plates	Example: queue of people
22. Important Viva Questions
Q1. What is a stack?
A stack is a linear data structure in which insertion and deletion are performed from one end called TOP. It follows LIFO.

Q2. What does LIFO mean?
Last In, First Out.

The element inserted last is removed first.

Q3. What is TOP?
TOP is a variable/index that indicates the position of the topmost element in the stack.

Q4. Why is TOP initialized to -1?
Because -1 represents that the stack is initially empty.

Q5. What is stack overflow?
It occurs when we try to insert an element into a full stack.

Q6. What is stack underflow?
It occurs when we try to delete an element from an empty stack.

Q7. What is the time complexity of Push?
O(1).

Q8. What is the time complexity of Pop?
O(1).

Q9. What is the time complexity of Display?
O(n).

Q10. What is the space complexity of an array-based stack?
O(n).

Q11. What is Peek?
Peek returns/displays the top element without deleting it.

Q12. Does Pop physically delete the value from your array?
No. Your code only decreases top. The old value may remain in the array, but it is outside the logical stack.

Q13. Why does Display use top + 1?
Because array indices start from 0, and we need to display indices from 0 through top.

range(0, self.top + 1)
prevents unused array positions containing 0 from being displayed.
