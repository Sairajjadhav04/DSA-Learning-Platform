Queue Data Structure
1. Definition of Queue
A Queue is a linear data structure that follows the FIFO (First In First Out) principle.

This means:

The element inserted first is removed first.

Real-life example
A queue at a ticket counter:

Front → [10] [20] [30] [40] ← Rear
If 10 entered first, it will be removed first.

Insertion is performed at the Rear.

Deletion is performed from the Front.

2. Queue ADT
ADT (Abstract Data Type) defines the behavior and operations of a data structure without focusing on its internal implementation.

A Queue ADT supports the following operations:

Operation	Description
Enqueue()	Insert an element at the rear
Dequeue()	Remove an element from the front
Peek()	View the front element
is_Empty()	Check whether the queue is empty
is_Full()	Check whether the queue is full
display()	Display all queue elements

4. Your Queue Code
class Queue:
def init(self, size):
self.size = size
self.queue = [0] * size
self.front = -1
self.rear = -1

# Check Empty
def is_Empty(self):
    return self.front == -1

# Check Full
def is_Full(self):
    return self.rear == self.size - 1

# Enqueue Operation
def Enqueue(self, item):
    if self.is_Full():
        print("Queue Overflow!!")
    else:
        if self.front == -1:
            self.front = 0

        self.rear += 1
        self.queue[self.rear] = item

        print(f"{item} entered inside the Queue")

# Dequeue Operation
def Dequeue(self):
    if self.is_Empty():
        print("Queue Underflow!!")
    else:
        item = self.queue[self.front]

        if self.front == self.rear:
            self.front = -1
            self.rear = -1
        else:
            self.front += 1

        print(f"{item} Removed From the Queue")

# Peek Operation
def Peek(self):
    if self.is_Empty():
        print("Queue is Empty!!")
    else:
        print(f"Peek / Front element is {self.queue[self.front]}")

# Display Operation
def display(self):
    if self.is_Empty():
        print("Queue is empty, nothing to display!!")
    else:
        print("Queue elements are:")

        for i in range(self.front, self.rear + 1):
            print(self.queue[i], end=" ")

        print()

7. Dequeue Operation
Definition
Dequeue removes an element from the front of the queue.

Because Queue follows FIFO:

The first inserted element is the first element removed.

Algorithm: DEQUEUE()
Step 1: Check whether the queue is empty.

Step 2: If FRONT = -1,
        print "Queue Underflow"
        Stop.

Step 3: Store QUEUE[FRONT] in ITEM.

Step 4: Check if FRONT = REAR.

Step 5: If FRONT = REAR,
        set FRONT = -1
        set REAR = -1

Step 6: Otherwise,
        increment FRONT by 1.

Step 7: Print the deleted ITEM.

Step 8: Stop.

16. Types of Queues
There are mainly four types of queues.

1. Linear Queue
A Linear Queue is the basic form of a queue.

Front → [10] [20] [30] ← Rear
Insertion at Rear

Deletion at Front

Follows FIFO

Your code implements:
Linear Queue using Array
Limitation of Linear Queue
Consider:

Size = 5

[10] [20] [30] [40] [50]
 F                   R
After removing two elements:

[10] [20] [30] [40] [50]
          F              R
Even though positions 0 and 1 are logically free, Rear is already at the last index.

Therefore, insertion may cause overflow.

This is called wastage of space in a linear queue.

2. Circular Queue
A Circular Queue connects the last position of the array back to the first position.

       ┌───────────────┐
       ↓               │
[10] [20] [30] [40] [50]
 ↑
 Front
When the rear reaches the last position, it can move back to the beginning.

It uses the modulo operator:

Rear = (Rear + 1) % Size
Advantage
Unused positions can be reused.

3. Priority Queue
In a Priority Queue, elements are removed according to their priority rather than only their insertion order.

Example:

Element     Priority

A              3
B              1
C              2
The element with higher priority is processed first.

Possible output order:

B → C → A
Priority queues are commonly used in:

CPU Scheduling

Graph algorithms

Dijkstra's Algorithm

Network routing

4. Deque
Deque means:

Double Ended Queue

Insertion and deletion can occur at both ends.

Front ← [10] [20] [30] → Rear
Operations include:

Insert Front
Insert Rear
Delete Front
Delete Rear
There are two common types.

Input Restricted Deque
Insertion allowed at only one end.

Deletion allowed at both ends.

Output Restricted Deque
Deletion allowed at only one end.

Insertion allowed at both ends.
